# סנכרון מערכת שעות הנדסאים ל-Apple Calendar 📅

כלי אוטומטי ב-Python שמושך את מערכת השעות היומית המעודכנת מאתר בית הספר [handasaim.co.il/schedule](https://handasaim.co.il/schedule) ישירות לתוך **Apple Calendar** (ב-Mac, ומסתנכרן ל-iPhone דרך iCloud).

---

## 🔍 מה גילינו בחקירת האתר?
1. האתר של הנדסאים בנוי ב-Astro ומשתמש ב-**Google Firebase Firestore** כמסד נתונים חי.
2. המערכת היומית מאוחסנת ב-Firestore באוסף:
   `projects/handasaim-website/databases/(default)/documents/schedules/{YYYY-MM-DD}`
3. בכל יום יש מסמך המכיל:
   - את רשימת השיעורים ושעות הצלצולים המדויקות (`lesson_num`, `time_start`, `time_end`).
   - מיפוי לפי כיתות (שם הכיתה מאוחסן כ-`"יא 1"`).
   - פרטי מורה ומקצוע לכל קבוצה.
   - התראות על שינויים, מילוי מקום או ביטולים (`cell_colors`, `cell_labels`).

---

## 🚀 איך להשתמש?

### 1. הרצה חד-פעמית (סנכרון מיידי)
פתח טרמינל והרץ:

```bash
# סנכרון להיום ומחר
python3 handasaim_sync.py --date both

# סנכרון לכל ימי השבוע הנוכחי
python3 handasaim_sync.py --week

# סנכרון ליום ספציפי
python3 handasaim_sync.py --date 2026-11-05
```

הסקריפט מסנכרן ישירות ליומן ה-iCloud שלך (ברירת המחדל: **"School Schedule"**), מוחק שיעורים ישנים מאותו יום (למניעת כפילויות), ומכניס את השיעורים המעודכנים שמסתנכרנים מיד ל-iPhone ולשאר המכשירים שלך דרך iCloud.

---

### 2. הפעלת סנכרון אוטומטי יומי ⏰
כדי שהיומן יתעדכן כל בוקר לבד ב-07:00 (או כשהמחשב נדלק):

```bash
python3 handasaim_sync.py --install-agent
```
זה יוצר `LaunchAgent` מובנה ב-macOS שידאג שהיומן תמיד מעודכן עם השינויים האחרונים של בית הספר.

---

### 3. התאמה אישית (מערכת אישית לפי מורים ומגמות) 👤
בכיתה י״א יש מספר קבוצות במקצועות כמו מתמטיקה (טכניוני / 5 יח"ל), מגמות (סייבר / ביוטכנולוגיה / פיזיקה), וחינוך גופני.

ניתן להעתיק את `config.example.json` לקובץ `config.json`:
```bash
cp config.example.json config.json
```
ולבחור את המורים שלך:
```json
{
  "class_name": "יא 1",
  "calendar_name": "מערכת שעות יא1",
  "teachers": {
    "מתמטיקה": "שפיר גיל",
    "פיזיקה": "גלעזר שרי",
    "סייבר 1": "אביטוב יורם",
    "סייבר 2": "שביט אופיר",
    "חינוך גופני": "טרצני גון"
  }
}
```
אם לא מגדירים מורים ספציפיים, הסקריפט יציג את כל האפשרויות של הכיתה באותו שיעור עם פירוט מלא של כל הקבוצות.
